合拍 Cojam — macOS 下载包（需要 Python）
===========================================

适用于 Apple Silicon 和 Intel Mac，需先安装 Python 3.11 或更新版本。
解压后可以启动完整会议室，也可以在本机生成 Cojam.app。

启动浏览器版
------------
1. 首次使用先安装 Python：https://www.python.org/downloads/macos/
2. 解压整个压缩包，将 Cojam 文件夹放在固定位置。
3. 双击「启动合拍.command」，浏览器会自动打开合拍。
4. 启动后的终端窗口保持打开；使用界面中的「退出」结束服务。
5. 在本机打开「新建项目 → 选择文件夹」，从系统对话框选取项目目录。

构建桌面版
----------
1. 双击「构建合拍桌面版.command」。首次构建需联网下载依赖。
2. 构建完成后，双击 dist/Cojam.app。可将它拖到「应用程序」。
3. dist/ 同时包含与当前 Python 架构对应的应用 ZIP。

若双击脚本遇到问题，可以打开终端，输入 /bin/bash 和一个空格，
把要运行的 .command 拖入终端后按回车。
本机构建的应用使用临时签名，未经 Apple 公证。

会议记录和设置保存在：~/Library/Application Support/Cojam/
换新版时替换程序文件夹即可，保留上述数据目录。
分发包不包含制作者的会议记录、登录凭据或设备数据。

运行本机 AI 前，仍需自行安装并登录对应 CLI（如 Codex、Claude）。
Mac 浏览器也可以通过邀请链接参加其他电脑的会议，前提是网络可达。
GitHub 更新服务暂不可用时，请由分发者手动提供新版压缩包。

桌面构建使用 pywebview 和 PyInstaller，依赖安装在包目录内的虚拟环境中。
