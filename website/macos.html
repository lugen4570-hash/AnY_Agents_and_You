Mac 安装教程

先装好 Python，再下载并解压合拍。想尽快开始就用浏览器版，想从「应用程序」打开就构建桌面版。

下载 macOS ZIP ↓
  1. 检查 Python
  2. 下载并解压
  3. 启动合拍
  4. 创建第一个项目

  1. 检查 Python

    打开 Mac 的「终端」，输入 python3 --version 后按回车。看到 Python 3.11 或更新版本，就可以继续。

    如果命令找不到，或版本低于 3.11，请到 Python 官网下载 macOS 安装程序。打开下载的 .pkg，按提示安装，然后重新打开终端检查一次。

    前往 Python 官网

  2. 下载并解压

    下载页面上方的 macOS ZIP，在 Finder 的「下载」里双击它。解压后打开整个 Cojam 文件夹，两个启动文件都在里面。

    把启动文件和旁边的程序文件放在一起，脚本才能找到它需要的内容。

  3. 选择一种启动方式

    浏览器版

    双击 启动合拍.command。终端启动服务后会自动打开浏览器。使用期间保留这个终端窗口，结束后在合拍里点「退出」。

    桌面版

    联网后双击 构建合拍桌面版.command。脚本会自动安装构建依赖。完成后，打开这个文件夹里的 dist/Cojam.app。也可以把应用拖进「应用程序」。

  4. 创建第一个项目

    在合拍里点「新建项目」，输入项目名称，再点「选择文件夹」。选择这次会话要用的工作目录，确认后创建项目。

    想让 Codex、Claude 等本机 AI 参与，再安装并登录对应工具，然后回合拍添加联系人。

遇到问题

Mac 提示无法打开文件 ＋

本机生成的桌面版未经 Apple 公证，系统可能显示安全提醒。确认文件来自合拍官网后，按提示类型查看 Apple 的说明。遇到恶意软件或文件损坏提示时，停止打开。

查看 Apple 的安全打开说明

构建完成后，在哪里找应用？ ＋

回到解压后的 Cojam 文件夹，打开 dist，再打开里面的 Cojam.app。如果终端还在安装依赖，等它显示构建完成。
