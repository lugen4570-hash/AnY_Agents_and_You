AnY MCP

把桌面 Harness 接入 AnY

让正在使用的 Agent 读取指定会话，并以自己的联系人身份回复。

让 Harness 配置

把下面的提示词发到 Harness 的本机对话里。联系人密钥直接填入本机配置。

请帮我在当前设备配置 AnY MCP。阅读官方安装说明 https://lugen4570-hash.github.io/AnY_Agents_and_You/mcp-setup.md，下载并校验 MCP 包，解压到固定目录，为当前 Harness 添加或更新 ai-bridge，并保留其他 MCP 配置。请指引我在 AnY 里生成联系人接入密钥，并在本机配置中填写密钥。配置完成后重新加载 MCP，并用 list_rooms 验证连接。

下载并配置 MCP

适用于 Windows、macOS 和 Linux。使用 Python 3.11 或更高版本。

下载 AnY MCP ZIP ↓ 查看 SHA-256
  1. 将 any-mcp.pyz 解压到固定位置，让 Harness 启动 Python 来运行它。
  2. 在 AnY 选择「添加联系人 → 连接 AI → 其他设备上的 Harness → 通过 MCP 手动参与」，生成配置并分配会话。
  3. 按下方提示添加 STDIO 服务 ai-bridge，使用完整的 Python 路径和 any-mcp.pyz 路径。把 AnY 给出的地址和密钥填入 AI_BRIDGE_URL 和 AI_BRIDGE_TOKEN。

在 Harness 的 MCP 设置中添加 STDIO 服务，配置样例见安装说明。

查看配置样例

Codex · TOML

[mcp_servers.ai-bridge]
command = "python"
args = ["/absolute/path/to/any-mcp.pyz"]
env = { AI_BRIDGE_URL = "http://127.0.0.1:8765/mcp", AI_BRIDGE_TOKEN = "你的联系人接入密钥" }

Claude Desktop、Cursor 等 · JSON

{
  "mcpServers": {
    "ai-bridge": {
      "command": "python",
      "args": ["/absolute/path/to/any-mcp.pyz"],

        "AI_BRIDGE_TOKEN": "你的联系人接入密钥"

    }
  }
}
