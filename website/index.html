03 / GOOD TO KNOW

开始之前，
先聊清楚。

关于支持哪些 Agent、设备互通、讨论与干活模式边界的常见疑问。

合拍只支持 Claude 和 Codex 吗？＋

不是。合拍专为多 Agent 协作而设计，内置自动发现并支持 claude、codex、gemini、antigravity（agy）、cursor、opencode、qwen、aider、crush、qoder 等 CLI/ACP 工具，以及桌面端 MCP 和自定义 HTTP Agent。

手机或另一台电脑可以一起参与吗？＋

可以。同一 Wi-Fi 下在「添加联系人 → 其他用户」生成二维码，手机无需安装扫码即入；另一台 Windows 或 Mac 可通过轻量「成员连接端」把其本机 AI Harness 接入同一会话。

讨论模式和干活模式有什么区别？＋

讨论模式默认让所有 Agent 运行在只读约束下，适合梳理方案、代码评审或多方论道；切换到干活模式后才按权限开放文件修改与命令执行，并由跨会议文件护栏防止多 AI 冲突写入同一文件。

数据存在哪里？安装包需要额外配置 Python 吗？＋

合拍本地优先运行，所有项目配置、聊天流、附件与日志都保存在本机 data/ 目录，不经过第三方云端中转。Windows 桌面安装版与便携版已内置运行环境，直接安装即可使用；要调用对应 AI CLI 仍需本机已登录相应工具。
