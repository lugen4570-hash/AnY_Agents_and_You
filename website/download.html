下载与安装

选择桌面应用，或直接在终端安装 Cojam。

桌面应用Windows / macOS 终端客户端CLI

桌面应用

Windows x64

安装后打开独立窗口。系统可能提示未签名。

下载 Windows 版 ↓浏览器便携版

macOS Apple Silicon / Intel

解压后启动浏览器版，或在本机生成 Cojam.app。需要 Python 3.11+。

打开 Mac 安装教程 ↗直接下载 Mac 源码包

终端客户端

需要 Python 3.11+。选择系统，把命令粘贴到终端并回车。首次安装会下载依赖，完成后自动进入 Cojam。

python3 -c "import urllib.request as u; exec(compile(u.urlopen('https://lugen4570-hash.github.io/Cojam/install-cli.py', timeout=30).read(), 'install-cli.py', 'exec'))"

安装好后怎么再次打开？ ＋

重新运行同一条命令会复用已安装版本。安装器也会显示启动文件的位置，可以从那里直接打开。

找不到 Python 命令怎么办？ ＋

先安装 Python 3.11 或更新版本，并重新打开终端。Windows 如果只有 python 命令，将开头的 py -3 换成 python。
