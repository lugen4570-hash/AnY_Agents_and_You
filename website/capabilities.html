多 Agent 协同

同一场会话可以请进多个擅长的 AI 与伙伴，每个主题下的协作方式可自由切换。

互相 @ 分工，观点当场交汇

在同一个输入框里同时 @Claude、@Codex、@Gemini 或 @Antigravity。各成员既看到彼此发言与附件，也能独立保持自己原本的连续记忆，不必在多个窗口之间反复复制粘贴上下文。

  • 不写 @ 时可唤醒会话内的全员参与，写明 @名称 则精准点名交接。
  • 支持整条消息或精确片段引用回复，并可在长对话中独立压缩单个 AI 的记忆长度。

设好议题与轮数，让 AI 彼此评议收尾

遇到关键架构抉择或复杂排障时，可由你指定议题、参与成员、发言轮数与最后收尾的总结人。各方按顺序回应并检视前一位成员的盲区，最终收敛成一份清晰的行动看板。

  • 在客户端或终端均可一键发起论道，随时查看当前轮次进度。
  • 支持中途随时请求提前收尾总结，不浪费额外轮次。

空闲与忙碌互不牵制，模型清晰可读

正在深入推演的 AI 不会阻断会话里的其他伙伴。你可以随时为空闲中的某个 Agent 切换模型与思考深度、刷新可用列表或调整启动参数，完全不打扰另一个仍在思考或回复的成员。

  • 直接呈现清晰可读的模型名称，免去繁琐的内部标识记忆。
  • 支持一键交由各工具自己的终端继续处理，完成后再收回至当前会话。

全渠道接入

无论是本机命令行工具、桌面端伴侣、朋友的手机，还是远在另一台电脑上的 AI，都能统一汇入同一场对话。

自动发现本机已安装的 AI 工具

打开「接入」界面即可扫描本机常见的命令行与协作工具，包括 claude、codex、gemini、antigravity、cursor、opencode、qwen、aider、crush、qoder 等，也支持一键向桌面编程工具写入协作入口。

  • 内置验证测试功能，添加前即可确认工具可启动并查看响应。
  • 复用你本机原本的账号登录与额度，不经第三方中转。

把另一台 Windows 或 Mac 上的 AI 请进桌

团队另一位同学的电脑上跑着好用的本地模型或专属工具？只要在 AnY 内生成一份连接配置并发给对方，对方运行轻量「成员连接端」即可进入待命接单状态，在你 @ 到他时自动回应。

  • 每台设备各自独立使用本机工作目录，本地文件不会擅自被远端读取。
  • 连接状态与心跳实时可见，随时按会话调配加入或移除。

同一局域网扫码即入，手机也能随时接管

AnY 支持两类人类接入方式：「邀请其他人」让你在特定会话里邀请同事或朋友以个人身份旁听与发言；「我的设备」则允许你用手机或平板扫码，以主人身份继续跟进进度。

  • 「邀请其他人」与「我的设备」严格隔离权限，访客只能看到被授权的那一场会话。
  • 跨网场景下只要填入可访问的会议室地址，同样能一键连线。

把自研 Agent 与 HTTP 工作流拉进会话

如果你自己在内部搭了 Agent 服务、脚本助手或自动化管线，只需填入接口地址与密钥，即可作为一个正规联系人坐在 AnY 的会议桌旁，接收任务并回传图文附件。

  • 支持自定义默认模型名、并发超时与会话级细粒度权限开关。
  • 外部发言同样记入统一的会议记录与项目审计流中。

工作台与安全

看得清全局状态，也守得住每一行本地代码的安全边界。

左边项目与联系人，右边专注当下的协作与产物

每场会话都带有独立的公告与待办看板、顶部成员在线胶囊、图片标注画板、剪贴板快捷上传以及结构化会话整理落盘，所有对话与产物默认只存在你电脑本地。

讨论模式与干活模式清晰切换

新会话默认开启「讨论模式」，所有 AI 仅阅读与分析，不改动你的磁盘文件；当你与伙伴拍板方案后，再一键切到「干活模式」，并为需要的成员放开写入与命令执行权限。

  • 每场会话可精细勾选「读消息 / 发言 / 唤起他人 / 改看板 / 发文件 / 允许干活」权限。
  • 支持一键切换只读评审，安心防止误改。
双模式护航
讨论默认只读约束 · 放心碰撞观点与方案
干活放开指定成员权限 · 协同落盘并验证

跨会话文件锁定，每一步改动皆可回看撤回

当多场会话或多个 AI 同时在同一个代码仓库里干活时，文件护栏会实时拦截冲突写入——同一文件同一时间只允许一位成员修改；你还能在右侧面板逐一预览某步修改详情，不满意随时按步撤回。

  • 与你自己的日常版本提交记录互不干扰，悄然记录每步快照。
  • 支持手动对特定敏感文件加锁，防止任何成员触碰。
