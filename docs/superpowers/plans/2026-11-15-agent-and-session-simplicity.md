# Agent 与会话操作简化

按用户指定方向实现：减少重复规则、将技术配置收进单一高级入口、删除时由应用解除关联。

1. Claude 的规则通过追加系统指令传递；Codex app-server 通过 developerInstructions 传递。普通聊天输入只保留消息、目标及看板更新。没有系统指令通道的接入使用精简规则，保留模式、权限和文件护栏约束；有记忆的会话仅在规则变化时更新。
2. Agent 默认页面只呈现名称、连接状态与连接操作。程序路径、参数、协议、模型索引、默认加入与权限进入一个高级设置入口；原配置和编辑能力保留。
3. 当前空闲会话可直接移入回收站，成功后自动切换至其他会话或空状态。删除联系人自动从所有会话移除，撤销密钥、待命与内部访问，保留历史消息。目标联系人有运行/排队任务时拒绝且不部分删除。
4. 回归覆盖系统指令分离、精简增量输入、当前会话删除后的页面状态、跨会话联系人清理、失败回滚与忙碌保护；使用独立数据进行实际浏览器验证。

保留此前 HTML 附件及弹窗拖动修复；不改用户已有的 OpenCode 预置修改，不重启运行中的会议室。

实现完成。Claude CLI 本机帮助确认支持追加系统指令；Codex 本机生成的 app-server schema 确认新建与续接均支持 developerInstructions。回归与真实浏览器检查通过，详见 `docs/UI_INTERACTIONS.md` 的当日记录。已纳入 2.8.2 完整发布。
