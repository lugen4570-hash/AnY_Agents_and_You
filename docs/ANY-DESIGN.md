# AnY 视觉约定

名称写作 AnY，来自 Agents and You。客户端侧栏使用[字标](../static/wordmark.svg)和[任意符号 ∀](../static/logo-collaboration.svg)。深青色 Y 的短竖带一笔微微外挑的衬脚，开口嵌入珊瑚色 A，A 与 ∀ 共用一条横笔。图标为透明底，浅色和深色界面共用同一配色。侧栏顶部用 40 px（窄屏 38 px），底部用 28 px，浏览器标签页使用同一图形。

官网导航使用带珊瑚色错版阴影的手绘斜体 AnY 字标。桌面安装图标和托盘使用几何 `∀`，CLI 使用 `∀ AnY`。

| 用途 | 浅色（日光画室） | 深色（泳池暮色） |
| --- | --- | --- |
| 客户端画布 | `#FCFBF7` | `#101D21` |
| 侧栏 | `#F2F7F4` | `#142328` |
| 浮层和输入区 | `#FFFFFF` | `#192C32` |
| 主要文字和按钮 | `#18302B` / `#1B5A48` | `#F3F2E7` / `#7DD3E8` |
| 焦点和工作状态 | `#1F849E` / `#D95D44` | `#7DD3E8` / `#F49E8A` |
| 用户气泡与共同目标 | `#E5F4F8` / `#FFF5D6` | `#1A3A44` / `#2E2A1C` |

Agent 保留各自的身份色。界面的层次用色彩语义、边线和明度来区分。

- 官网用原生 HTML、CSS 和 JavaScript。首屏从晴日地景取色，以草地绿、池水蓝、鹅黄和珊瑚粉构成多色画面。字标与标题分段入场，协作演示把行进的光点、路线和逐条出现的消息连成约一秒的过程。换模式或点击「重播」可再次观看。开启减少动态效果时保留静态演示与模式切换。下载页按平台显示安装包或终端命令，支持键盘切换。
- 客户端（[index.html](../index.html)、[static/studio.css](../static/studio.css)、[static/harness-ui.css](../static/harness-ui.css)、[static/app-meeting.js](../static/app-meeting.js)）统一同步 `studio.css` 与 `harness-ui.css` 的显式 `light` / `dark` 霍克尼明亮多色画室主题。浅色采用日光画布白主区、晨雾浅青侧栏与池水蓝高亮；深色采用泳池暮色深青底与亮池水青/珊瑚粉对比。共同目标以暖鹅黄便签配珊瑚色左条置顶；聊天流以池水浅蓝用户气泡、Agent 彩色徽章与左侧专属色竖线纯白卡片区分发言者，消息操作常态弱化并在悬停或聚焦时显现；右侧抽屉按目标、看板（待办/公告/已完成）、正在改的文件与产出加上彩色语义左条。
- CLI（[bridge/terminal.py](../bridge/terminal.py)）沿用 Textual 和 Rich，采用 `#101c20` / `#17272c` 深松青底搭配草地嫩绿（`#b4e197`）、池水晴空蓝（`#7fd4e6`）、阳光鹅黄（`#f4d98c`）、珊瑚暖粉（`#f49e8a`）与暖画布白（`#f4f2e6`）。启动页用草绿、池水蓝和珊瑚色画出 `∀`，收成单行 `∀ AnY`；聊天区使用圆角边框卡片区分发言者（`◆ 你` 右缩进草绿框、`● Agent` 与 `○ 成员` 各自独立色框、`─ 系统` 居中细分割线），并在开关右侧栏或缩放窗口时自动重排宽度；按 `F3` 展开的右侧栏用独立色标头与水平分割线列出会议目标、待办、公告、已完成、正在改的文件、论道及成员，并按单元格宽度对齐折行。动效遵循 `NO_COLOR` 和 `TEXTUAL_ANIMATIONS=none`。

官网与客户端此次调整参考大卫·霍克尼明亮多色画室风格与 Taste Skill 规范。浏览器验收使用本机 Chromium。
