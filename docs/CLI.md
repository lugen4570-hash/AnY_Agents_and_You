# AnY 终端客户端

打开[官网下载页的终端客户端](https://lugen4570-hash.github.io/AnY_Agents_and_You/download.html#cli)，选择操作系统并复制一键安装命令。macOS 和 Linux 使用 `curl ... | bash`，Windows PowerShell 使用 `irm ... | iex`。本机没有 Python 3.11+ 时，安装脚本会准备独立运行环境。交互式终端会直接打开 AnY，已有兼容后台时会复用。

安装后运行 `any --help` 查看命令。macOS 和 Linux 如果当前终端找不到 `any`，可按安装脚本提示将 `$HOME/.local/bin` 加入 PATH。

如果已经有源码，在源码目录运行：

```sh
python -m pip install -e ".[cli]"
```

如果系统提供的命令是 `python3`，请用 `python3` 代替 `python`。如需隔离依赖，可以先创建并激活 Python 虚拟环境。

直接运行 `any`。桌面后台已运行时会复用它，单独使用终端时会自动启动后台。也可以用 `any serve` 在当前终端前台运行后台。终端和桌面连到同一个后台时会看到同样的项目、会话和消息。

## 在终端开会

运行 `any` 会进入项目首页。启动时 ∀ 标志旁有一段短暂的动效。设置 `TEXTUAL_ANIMATIONS=none` 或 `NO_COLOR` 可关闭它。首页按项目列出会话及其状态。用 `↑`、`↓` 选择，按 `Enter` 打开。也可以运行 `any open "会话ID"` 直接进入指定会话。

输入 `/` 就会在输入框上方打开命令列表。继续输入可以筛选，`↑`、`↓` 选择，`Tab` 补全，`Enter` 确认，`Esc` 收起。需要参数的命令会先补全命令名，再显示可用的成员、模式或模型。输入 `@` 可按成员名或 ID 补全。要发送以 `/` 开头的普通消息，在开头多输入一个 `/`，例如 `//tmp` 会发送 `/tmp`。

聊天标题下方显示用户和 Agent 的简要状态。按 `F3` 或点击「成员」展开成员详情、会议目标和看板。宽窗口在右侧展开，窄窗口切换到完整详情页。按 `F2` 或点击「项目」返回首页。切换会话会保留各自未发送的草稿。聊天区支持 Markdown，成员正在生成时会在输入框上方显示进度。

| 操作 | 快捷键或命令 |
| --- | --- |
| 查看项目并切换会话 | `F2` 返回项目首页，方向键选择，`Enter` 打开 |
| 搜索并恢复已有会话 | `Ctrl+R` 或 `/resume`，按会话标题、项目或目录筛选 |
| 新建项目 | `/project`，填写项目名称和工作目录 |
| 新建会话 | `Ctrl+N` 或 `/new`，可选择已有项目或填写工作目录 |
| 发言 | `Ctrl+L` 聚焦输入框，`Enter` 发送，`Shift+Enter` 或 `Alt+Enter` 换行 |
| 重用前一条发言 | 光标在输入框最上面一行且候选已收起时，按 `↑` 浏览当前会话的发言历史 |
| 查看成员、目标和看板 | `F3` 展开或收起会话详情，`/status` 打开详情 |
| 开始或结束论道 | `/debate [议题]` 打开设置，选择轮数、参辩成员和总结人；`/debate-finish` 请求结束轮流发言并总结 |
| 继续论道 | `/debate-continue [补充意见]` 沿用原议题，填写对上次总结的反馈并设置要再辩的轮数 |
| 发现并接入本机 Harness | `/scan` 查找程序，`/connect ID cli` 或 `/connect ID acp` 进行连接检查 |
| 查找联系人并加入会话 | `/agents` 列出已配置的联系人，`/invite ID` 邀请已启用的联系人 |
| 更新目标和待办 | `/announce 目标`、`/todo 内容`、`/done 编号` |
| 管理回复 | 生成期间按 `Esc` 或 `/stop [ID]` 停止回复，`/compact [ID]` 压缩上下文 |
| 切换模式 | `/mode discuss` 或 `/mode work` |
| 设置模型 | `/model` 依次选择可配置的成员、模型及可选思考强度。也可输入 `/model ID MODEL [EFFORT]`，用 `default` 选会话默认值 |
| 帮助和退出 | `F1` 或 `/help`，`Ctrl+Q` 或 `/quit` 退出客户端 |

已连接的 Agent 仍由 AnY 后台调度。用 `@codex` 等成员 ID 发言后，聊天区会显示回复，输入框上方会显示正在生成的进度。要在原生终端继续一个受支持的现有会话，输入 `/handoff codex`，再把显示的续接命令复制到另一个终端运行。结束后输入 `/return codex`，把这个成员收回到 AnY。其他支持交接的 CLI 可以替换相应的成员 ID。

论道和续论的首轮由参辩 Agent 并行独立作答，首轮结束后统一发表。后续按顺序讨论，Agent 可以在没有新意见时跳过，整轮照常计数。最多轮数留空表示不限，填 `0` 则由指定的总结人直接作答。`/debate-finish` 会让后台在达到最少轮数后收尾并总结。

全屏终端客户端目前从源码安装，可连接本机桌面版、便携版或源码后台。先安装并登录对应的 Harness。自定义接入、执行端设置与权限细项可以在 AnY 桌面端配置。

## 脚本入口

`rooms`、`send`、`messages` 输出 JSON。`send` 支持用 `-` 从标准输入读入多行文本。用 `messages` 返回的 `next` 作为下次请求的 `--since` 游标。

```sh
any rooms
any open "会话ID"
any send "会话ID" "@codex 请先总结当前目标"
any messages "会话ID" --since 0
```

客户端默认连接 `127.0.0.1:8765`。自定义端口可用 `any --port 8877`，或者设置 `ROUNDTABLE_PORT`。同一套命令中的 `--port` 写在子命令前。
